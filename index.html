Manual Review — before final video

Only fully dispatched productions with all linked generation jobs completed are ready. This UI lists outputs and persisted review state; decisions run in the authenticated n8n editor, not an unauthenticated webhook.

Open authenticated Review workflow

  1. Set Review Request to the explicit production JobID and action: 'list'; execute manually to persist the current snapshot.
  2. Inspect every output in Capture Output Snapshot (and the previews below).
  3. Set action: 'approve' or 'reject' and a reason; execute again. Approval fails if outputs changed since listing or any job is incomplete.

Approve/reject are unavailable in this UI until authenticated server-side review integration is configured. No final-video assembly workflow exists; approval does not generate a final video.
