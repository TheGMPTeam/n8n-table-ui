# Bind-first updater and local activation identities

The standalone copied host worker is distinct from the application checkout and Docker image. Installing that worker is an operator-only copy/restart; browser Apply never commits or pushes source, changes the worker, or manages other services.

Check validates independent manifest `uiSha` and `serverSha` against exact served HTML, mounted backend bytes, and startup `/updates/identity`; records the unchanged Docker image ID and loaded worker hash. Local deployment anchors are private Git snapshot commits, not public GitHub release commits. Create them with Git object plumbing and an isolated index; do not alter the operator worktree/index or assign the public latest SHA to patched bytes. Local CLI `register UI_SHA SERVER_SHA` compares each exact Git blob before writing the manifest. There is deliberately no public registration route.

Runtime classification uses actual Docker mounts of the fixed n8n-table-ui container. Mounted index.html means `databind` + `none`. Mounted proxy-server.cjs means `databind` + `restart`, with only `docker restart n8n-table-ui`, no build/pull. Dockerfile/.dockerignore, actual dependency manifests/lockfiles, the baked webhook template, or unmounted active components mean `full` + `image`. Script-only package.json changes are compared structurally and do not imply image dependencies (this image does not COPY package.json or invoke npm). Documentation/tests and separately managed updater infrastructure mean `noRuntimeUpdate` + `none` and require no Apply. Unknown paths fail closed; wrong bind-source paths and Docker image drift fail closed. Classification is specific to this repository's Dockerfile COPY/runtime contract; new runtime files must be reviewed explicitly.

Apply retains fixed branches/repository/paths, dirty-worktree refusal, checked SHA re-fetch, downgrade confirmation, private socket, LAN opt-in, same-origin proxy checks, lock, staged test/build and rollback. Backend bind writes preserve the mounted file inode and back up/restore backend bytes on failed postvalidation. A successful backend bind change leaves a tracked backend worktree delta; future Apply remains blocked pending operator source reconciliation rather than silently resetting it. Static-only updates never restart the container. Image operations remain UI-only compose builds. Tests use isolated real Git fixtures and mocked Docker actions, not production Apply.

Existing manifest database fields remain `uiSha`, `serverSha`, `hashes`. Version labels remain operator-owned. Update metadata can record `currentUiCommit`/`currentServerCommit` as exact private anchors without replacing public-source attribution.
