# Bundled build sources and license boundaries

- Pocket source: existing local checkout of `teddybear082/pocket-tts-openai_streaming_server`, upstream commit `0327291dc88e922521a84b7ccf86b3e31423d03e`; the actual local application source (including browser clone/upload changes) is bundled. Its original MIT license is preserved in `pockettts/LICENSE`. No upstream voice recordings, private certificates, model weights, voice-cache entries, auth database or active `.env` is included. `voices/` is deliberately empty and must be populated only with authorized operator references. Omitted logo artwork does not supply a new voice.
- CPU startup helper: actual operator-local `production-readiness/pocket-tts-quality/cpu_startup.py`, copied as text. It imports Pocket before applying the CPU thread configuration and is mounted read-only into `/app/cpu_startup.py`. Offline mocked-Torch verification is not a fresh model boot.
- FFmpeg API is an external operator-supplied compatible image, selected by `FFMPEG_IMAGE`. No local FFmpeg API implementation, build context, source archive or source patch is distributed. The example local tag is not a public image. Operators obtain/build their own image from separately authorized source; HTTP workflow consumers remain included. No redistribution rights or model/voice rights are asserted.
- UI: existing repository declares ISC; a standard ISC license text is included at repository root. Runtime modules and settings are packaged separately and no private state is copied into the image.
- Container images and model weights remain external dependencies with their own licenses. The existing mutable `latest` tags were preserved, not represented as pinned reproducible artifacts.
